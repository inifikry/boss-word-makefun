# One Word for the Boss

Entry for the make.fun bounty
`u-swift-badger-44-one-word-for-the-boss-6b48c735` — "One Word for the Boss".

## The word

**Arsonist** — the boss who starts the fires, then expects you to put them
out. One word, no caption, no explanation: it lands on its own at lunch,
rings true (every office has a boss who manufactures emergencies), stays
fresh (not the first word anyone reaches for), and travels from a kitchen
to a warehouse to an office.

## How to run

```sh
python3 main.py
```

Writes exactly one word to `/output/entry.txt` (8 characters, deterministic —
the same output on every run).
